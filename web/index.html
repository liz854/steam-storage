不知道 Steam 装在哪？

最稳的办法：打开 Steam 客户端 →「设置」→「存储」，点某个库右边的齿轮 →「本地文件」，显示的就是那个路径。

  • Windows 默认：C:\Program Files (x86)\Steam
  • 自建的库常见于：D:\SteamLibrary、E:\SteamLibrary
  • 直接选 steamapps 文件夹本身也行，会自动往里找清单
  • macOS：~/Library/Application Support/Steam
  • Linux / Steam Deck：~/.local/share/Steam
